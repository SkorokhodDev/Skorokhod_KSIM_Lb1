# Звіт з лабораторної роботи №1

**Тема:** Опис імітаційних моделей та проведення обчислювальних експериментів.**Варіант:** 2. Climate Change. Дослідження парникового ефекту та зміни температури земної поверхні.

## 1. Вербальний опис моделі

**Вербальний опис моделі:** Модель імітує енергетичний баланс Землі та механізм парникового ефекту. Агентами виступають кванти енергії — сонячні промені жовті та інфрачервоне теплове випромінювання червоні. Сонячні промені падають на земну поверхню: частина з них одразу відбивається в космос, а частина поглинається Землею, перетворюючись на тепло. Нагріта Земля випромінює інфрачервоні промені назад в атмосферу. Парникові гази CO2 та хмари затримують це теплове випромінювання, відбиваючи його назад до поверхні, що призводить до підвищення глобальної температури планети.

**Керуючі параметри:**

- sun-brightness — яскравість сонця, що визначає кількість та інтенсивність сонячної енергії променів, яка надходить на планету.
- albedo — альбедо відбивна здатність поверхні Землі. Чим вищий показник, тим більше сонячних променів відбивається одразу, не перетворюючись на тепло.
- Кнопки add CO2 / remove CO2 — дозволяють додавати або видаляти молекули вуглекислого газу в атмосфері, імітуючи рівень парникових газів.
- Кнопки add cloud / remove cloud — дозволяють додавати або прибирати хмарність, яка також перешкоджає виходу тепла в космос.

**Внутрішні параметри:**
- Поточна кількість доданих хмар на небі керується користувачем.
- Стан енергії: промінь рухається вниз як сонячна радіація або вгору як відбите тепло.

**Показники роботи системи:**
- temperature — поточна глобальна температура земної поверхні у градусах.
- CO2 amount — поточна кількість молекул вуглекислого газу, доданих в атмосферу.
- Графік Global Temperature — візуалізує динаміку зміни температури з плином модельного часу тиків.

**Примітки:** Температура в моделі є динамічною величиною і постійно коливається, тому для фіксації результатів потрібно дочекатися стабілізації графіка на певному рівні.

**Недоліки моделі:** Модель є сильним спрощенням реальної кліматичної системи. В ній відсутній динамічний зворотний зв'язок: наприклад, в реальності при підвищенні температури тануть льодовики, що природним чином знижує альбедо, ще більше прискорюючи нагрівання. Також не враховується поглинання вуглекислого газу Світовим океаном та рослинами вуглецевий цикл.


## 2. Обчислювальні експерименти

### Експеримент 1. Залежність температури від концентрації CO2 парниковий ефект
Досліджується, як додавання молекул вуглекислого газу впливає на утримання тепла атмосферою. 
Початкові умови: 
- albedo = 0.6, 
- sun-brightness = 1.0, хмари відсутні.

Тривалість одного тесту: 500 тіків

| **Кількість CO2** | **Максимальна температура на 500-му тіку** |
| ----------------- | ------------------------------------------ |
| 0                 | 14,7                                       |
| 25                | 15,5                                       |
| 50                | 14,1                                       |
| 75                | 14,5                                       |
| 100               | 14,4                                       |
![[Pasted image 20261101162407.png|512]]

Згідно з графіком, збільшення кількості молекул CO2 від 0 до 100 не продемонструвало очікуваного стабільного зростання температури. Натомість фіксована максимальна температура коливалася хаотично в межах від 14.1 до 15.5 градусів, причому найнижче значення 14.1 було отримано при досить високому рівні CO2 — 50 молекул.
Відсутність чітко вираженого парникового ефекту в цих результатах пояснюється тим, що фіксувалися короткочасні максимальні піки, а не стабілізований стан системи. Рух теплових променів у моделі має випадковий характер, тому миттєві значення температури сильно стрибають. Модель має суттєвий недолік, не показуючи середнє значення температури в ході всієї симуляції.

### Експеримент 2. Вплив відбивної здатності поверхні альбедо на клімат
Досліджується, як зміна відбивної здатності Землі наприклад через вирубку лісів або танення льодів впливає на температуру при стабільному рівні CO2.
Початкові умови: 
- sun-brightness = 1.0, 
- CO2 amount = 15, хмари відсутні.
Тривалість одного тесту: 1000 тіків

| **Альбедо** | **Температура на 1000-му тіку** |
| ----------- | ------------------------------- |
| 0,2         | 23,4                            |
| 0,4         | 20,6                            |
| 0,6         | 18,3                            |
| 0,8         | 15,2                            |
| 1,0         | 12                              |
|             |                                 |
![[Pasted image 20261101162707.png|573]]

Дивлячись на графік можна сказати, що зі збільшенням показника альбедо від 0.2 до 1.0 температура на 1000-му тіку стабільно та послідовно знижується з 23.4 до 12. Це свідчить про чітку залежність: поверхня з вищим рівнем альбедо відбиває більше сонячної енергії назад у космос, запобігаючи її перетворенню на тепло. Відповідно, чим нижча відбивна здатність поверхні як при значенні 0.2, тим більше сонячної енергії поглинається планетою, що призводить до суттєвого нагрівання до 23.4.

### Експеримент 3. Вплив сонячної активності на температуру

Досліджується, як зміна потужності випромінювання Сонця впливає на клімат при незмінних параметрах атмосфери Землі. 
Початкові умови: 
- albedo = 0.6, 
- CO2 amount = 0, хмари відсутні. 
Тривалість одного тесту: 1000 тіків

| **Яскравість сонця** | Температура на 1000-му тіку |
| -------------------- | --------------------------- |
| 0,5                  | 14,8                        |
| 1,0                  | 18,8                        |
| 1,5                  | 23,6                        |
| 2,0                  | 24                          |
| 2,5                  | 25,6                        |
![[Pasted image 20261101162652.png|602]]

Отже, зі збільшенням параметра яскравості сонця від 0,5 до 2,5 температура на 1000-му тіку стабільно зростає з 14,8 до 25,6 градусів. Це підтверджує пряму залежність глобальної кліматичної температури від інтенсивності вхідного сонячного потоку. Чим вищий показник сонячної активності, тим більше енергії досягає поверхні планети і поглинається нею, що призводить до пропорційного зростання температури навіть за умови повної відсутності парникових газів.
